# ABOKICHI

A responsive e-commerce frontend inspired by the ABOKICHI website, built using HTML, CSS, and vanilla JavaScript.

## Features
- Responsive design
- Product listing
- Product filtering & sorting
- Product details page
- Login/Register page
- Contact page

## Tech Stack
- HTML5
- CSS3
- JavaScript
